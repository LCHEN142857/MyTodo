# MyTodo

一款透明、贴附桌面的 Windows 待办清单应用。基于 Electron 开发。

## 项目背景

MyTodo 的设计初衷是做一个轻量级的半透明悬浮待办，不是一个占满屏幕的传统窗口。它待在屏幕角落，让你随时记录任务，不需要时也不会挡住其他内容。可以把它理解成一张会管理待办事项的便利贴。

## 功能特性

### 窗口
- 无边框透明窗口，圆角设计
- 透明度可调（0%–100%），背景随心调，按钮和文字不受影响
- 置顶功能：置顶后显示在所有窗口最上层；取消置顶后可被其他窗口遮挡
- 四边可拖拽调节大小

### 待办管理
- 快速新增：输入框输入文字，回车或点击加号即可创建
- 勾选完成：点击勾选框，已完成项显示删除线并移入历史记录
- 点击编辑：点击待办文字直接编辑，回车保存，Esc 取消
- 实时搜索：输入框输入关键词，列表实时过滤
- 悬停删除：鼠标移到待办上显示 × 按钮，点击删除

### 历史记录
- 点击右上角 History 按钮切换到历史视图
- 恢复功能：每条历史记录旁有恢复按钮（向上箭头+横杠图标），点击可恢复到待办列表
- 删除单条：点击 × 按钮删除单条历史
- 清空历史：右下角 Clean histories 按钮一键清空
- 左下角显示历史记录数量

### 设置（S 按钮）
- 透明度滑块（0%–100%）— 仅调节背景透明度，按钮和文字颜色不变
- Exit 退出按钮

### 智能滚动条
- 内容不超出窗口时不显示滚动条
- 内容超出后，鼠标靠近右侧边缘时滚动条出现
- 鼠标离开 3 秒后滚动条自动消失

## 技术栈

| 层级 | 技术 |
|------|------|
| 框架 | Electron 28 |
| 语言 | JavaScript (ES6+) |
| 界面 | HTML5 + CSS3（无前端框架） |
| 打包工具 | electron-builder 24 |

```

├── main.js          # 主进程：窗口创建、IPC 处理、数据持久化

├── .npmrc           # npm 镜像配置（国内加速下载）
├── build/
│   ├── icon.png     # 图标源文件（1920×1920 PNG）
│   └── icon.ico     # 生成的 ICO 文件（多尺寸：16–256px）

    ├── index.html   # 界面布局
    ├── styles.css   # 全部样式（暗色主题、透明度、滚动条）
    ├── renderer.js  # 全部 UI 逻辑（增删改查、搜索、编辑、视图切换、滚动条）

```

## 数据存储

数据以 JSON 文件形式持久化存储在磁盘上：

```
%APPDATA%\MyTodo\mytodo-data.json
```

### 数据结构

```json
{
  "todos": [
    {
      "id": "唯一标识",
      "text": "待办内容",
      "completed": false,
      "createdAt": "ISO 8601 时间戳"
    }
  ],
  "history": [
    {
      "id": "唯一标识",
      "text": "待办内容",
      "completedAt": "ISO 8601 时间戳"
    }
  ],
  "settings": {
    "opacity": 0.92,
    "isPinned": false
  }
}
```

- **写入防抖**：400ms 防抖，避免频繁编辑时过多的磁盘写入
- **启动读取**：应用启动时一次性加载所有数据
- **无数据库依赖**：JSON 文件对于这个量级的待办数据完全够用，简单可靠

## 快速开始

### 环境要求

- [Node.js](https://nodejs.org/) 16+（推荐 LTS 版本）
- PowerShell 5+（Windows 10/11 自带）

### 安装依赖

```bash
git clone <仓库地址>
cd MyTodo
npm install
```

### 开发模式运行

```bash
npm run dev
```

启动应用并自动打开 DevTools 调试工具。

### 普通运行

```bash
npm start
```

## 打包构建

### 一键打包（推荐）

```powershell
.\build.cmd
```

脚本会自动完成：
1. 检测并安装依赖（如果 `node_modules` 不存在）
2. 从 `build/icon.png` 生成 `icon.ico`（如果尚未生成）
3. 通过 electron-builder 构建 portable exe 和 NSIS 安装包
4. 用 rcedit 给未打包的 exe 设置图标
5. 输出构建结果摘要

### 手动打包

```bash
# 同时构建便携版和安装版
npm run build

# 或单独构建
npm run build:portable   # 输出 dist\MyTodo-Portable-1.0.0.exe
npm run build:nsis       # 输出 dist\MyTodo-1.0.0-x64.exe
```

### 构建产物

| 文件 | 类型 | 大小 |
|------|------|------|
| `MyTodo-Portable-1.0.0.exe` | 便携版（免安装，双击即用） | ~66 MB |
| `MyTodo-1.0.0-x64.exe` | NSIS 安装包（含桌面快捷方式） | ~66 MB |

均输出到 `dist/` 目录。

## 使用说明

| 操作 | 方式 |
|------|------|
| 新增待办 | 底部输入框输入文字 → 回车或点击 + |
| 完成待办 | 点击勾选框 |
| 编辑待办 | 点击待办文字 → 编辑 → 回车保存 / Esc 取消 |
| 删除待办 | 鼠悬停在待办上 → 点击 × |
| 搜索待办 | 搜索框输入关键词（实时过滤） |
| 查看历史 | 点击右上角 History 按钮 |
| 恢复历史项 | 悬停 → 点击恢复图标（↑带横杠） |
| 置顶窗口 | 点击左上角图钉按钮 |
| 调节透明度 | 点击 S → 拖动滑块 |
| 退出应用 | S → Exit 按钮 |
